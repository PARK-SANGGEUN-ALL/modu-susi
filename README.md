# 모두의 학생, 학부모를 위한 수시 원서잡기

내신 등급을 넣으면 **학생부종합·학생부교과**에서 지원 가능한 전국 대학 모집단위를
**안정 / 적정 / 소신 / 상향**으로 정리해 보여주고, **수시 6장 원서함**에 담아 비교·인쇄할 수 있습니다.

## 사용법
1. **내 내신 등급 입력** — ＋/− 버튼, 슬라이더, 빠른 선택 지원
2. **전형 선택** — 학생부종합 / 학생부교과 / 둘 다
3. **조건 좁히기** — 지역(권역 다중 선택) · 대학(다중 선택) · 학과 키워드 검색 · 의치한약수(전체/의대/치대/한의대/약대/수의대)
4. **결과 확인** — 안정·적정·소신·상향 탭에서 모집단위를 살펴봅니다
5. **원서함에 담기** — 마음에 드는 카드를 담아 📋 내 원서함에서 6장을 비교
6. **인쇄** — [인쇄 · PDF 저장]을 누르면 담은 원서만 A4 **1장**으로 출력(6칸 + 균형 요약 + 메모란 + 출처)

### 연관 학과 키워드 검색
19개 학과군 사전을 내장해 검색어를 자동으로 넓힙니다.
- `컴퓨터` → 소프트웨어 · 인공지능 · 정보통신 · 데이터 · 게임 · 반도체
- `간호` → 보건 · 임상병리 · 물리치료 · 응급구조 · 치위생

확장된 키워드는 칩으로 표시되며 눌러서 좁히거나 **연관 확장 끄기**로 정확 일치 검색을 할 수 있습니다.

## 자료 출처와 기준
- 출처: **대입정보포털 '어디가' 2026학년도 대학별 입시결과 공개자료** (전국 200개교)
- 지표: **최종등록자 학생부 환산등급 70%컷** — 합격자의 70%가 이 등급 이내
- 수록: 학생부종합 6,233개 + 학생부교과 10,308개 = **16,541개 모집단위**
- 주간·야간 분리 모집은 모집단위명에 `(야간)` 표기
- 참고용 자료입니다. 대학·연도·전형 방법에 따라 결과가 달라지므로 **최종 지원은 대학별 모집요강**을 확인하세요.
